# 预标注实例融合与类别裁决

## 要解决的问题

同一目标可能收到全图、切片和不同模型的多个候选框；检测模型还可能把目标的局部误识别为另一项目类别。仅用框 IoU 与分数做 NMS 容易留下局部重复框，或误删相邻的真实目标。SAM 提供实例形状证据，但不提供类别语义，因此跨类别合并必须再有类别模型的证据。

本阶段位于已有候选融合和风险标记之后、最终规则精简之前。先前的 XML 不会自动改写，用户需选定范围重新预标注；原 XML 按现有版本机制保留。

## 当前实现

1. **候选召集**：对框 IoU ≥ 0.25，或较小框至少 55% 落在另一框中的候选建立关系。跨类别关系优先取样；每图最多 32 个候选框提示。需要辅助判断时再加入最多 8 个 YOLO11n 锚框，同时对弱重叠同类候选加入最多 4 个联合框提示。存在类别锚框时会相应减少候选提示数，总提示最多 36 个。无相交关系时不加载 SAM。
2. **掩码获取**：SAM 2.1 Tiny 对一张图只编码一次，掩码每批最多解码 8 个，缩放后的最长边不超过 1024 像素。一批提示框返回的掩码数量不足时，会在同一次图片编码下拆成更小批次重试；单框仍失败才将该框标为无效，不丢弃其他有效掩码。整张图片推理异常时保留原候选，后续图片不再反复尝试失败的 SAM。
3. **同类融合**：候选掩码 IoU ≥ 0.80，或掩码 IoU ≥ 0.35 且较小掩码至少 90% 被较大掩码覆盖，可视为同一目标。组内候选必须两两满足条件，避免拥挤目标被链式合并。对于框关系较弱的同类候选，另以坐标联合框提示 SAM：候选掩码至少 85% 落入联合框掩码，且组内候选掩码两两有实质交集时才合并。输出框取组内坐标并集，避免局部框缩小目标。
4. **跨类实例与类别裁决**：只有图中存在跨类别相交候选时，才按需运行已启用的 YOLO11n；其检测分数至少为 0.45。它仅请求权重已知且在当前候选中出现的项目类别。候选掩码至少 80% 落在同一 YOLO11n 实例掩码中，掩码 IoU ≥ 0.15，且两个锚框的归属分数差不能小于 0.08，才归到该实例。同一锚框下的候选还须通过掩码交集或包含关系形成连通分组；互不相交的相邻目标不能仅凭一个宽大的锚掩码被合在一起。只有组内原候选已经包含 YOLO11n 的类别、组内所有类别均被 YOLO11n 支持，且组内至少两种类别时，才输出单个框。输出使用辅助模型的类别、框和对应分数；原候选类别记录在 `alternate_labels`。
5. **整图实例锚点**：切片会把一个完整目标切成多块，还可能给局部块报错类别。当 SAM 已为整图候选生成掩码时，以有整图来源、分数至少 0.45 的候选作为锚点；已被 YOLO11n 核验的整图候选可使用较低原分数。仅吸收纯切片候选，要求其框至少 70% 落在整图框内、掩码至少 80%（同类）或 92%（跨类）落在整图掩码内，且整图掩码显著大于局部掩码。若有两个整图锚点的匹配度接近，则不吸收该局部候选。输出保持整图框和整图类别；跨类别时保留原类别并标记待核验。这条路径可处理 YOLO11n 在整图上未检出、但主模型已给出完整目标的情况。
6. **退让与审核**：YOLO11n 缺失、停用、类别不在其权重中、没有匹配检测或归属模糊时，先尝试上述整图实例锚点；仍无足够掩码证据时保留原候选。跨类别融合结果标记 `class_conflict`，在审核队列中提高优先级，画布详情显示原候选类别。两个掩码 IoU ≤ 0.20 且包含率 ≤ 0.40 时，除下文严格切片截断特例外，后续规则不得把这两个实例合并；其他模糊情况仍由原规则判断。
7. **低分同类碎片**：少数纯切片小框被高分整图框几何包含，但 SAM 在小框中分出了背景碎片。仅在类别相同、模型来源相交、整图分数 ≥ 0.65、小框分数 ≤ 0.55 且不超过整图的 75%、整图框面积至少是小框 8 倍、小框至少 82% 位于整图框内、小框贴着切片边界、掩码在自身框内填充率 ≤ 18%，并且只有一个可归属整图框时，才把小框吸收到大框。输出保持大框坐标与分数，标记 `weak_mask_merge` 进入人工核验。掩码形状正常的独立小目标保留。
8. **切片截断实例归属**：对 SAM 将同一目标分成不同掩码的情况，还核对真实切片窗口。一个分数 ≥ 0.65 的完整框与纯切片框必须同类、共享模型来源；切片框分数 ≥ 0.55 且不超过完整框的 105%，面积至多为完整框的四分之一，至少 95% 位于完整框内。切片框的一边须距实际切片边界不超过 5 像素，完整框在该边界外还要延伸至少 40 像素或切片框相应边长的 12%。若另一整图框也覆盖该切片框至少 50%，便不使用此退让规则。仅有唯一归属时保持完整框坐标和分数，并标记 `tile_fragment_merge` 待核验。
9. **单框 SAM 失败时的窄条回退**：若 SAM 对切片框未返回有效掩码，但完整框掩码有效，只对分数 ≤ 0.55、完整框面积至少为局部框 20 倍、局部框最窄边相对完整框 ≤ 15%、至少 97% 被包含的切片窄条使用上述真实切片边界和唯一归属检查。该结果同样标记 `tile_fragment_merge`；不满足任一条件即保留局部框。

所有图像操作按 EXIF 定向后的宽高解释坐标。整图检测、切片裁剪、SAM、边界裁剪和审核画布使用同一方向；旧版对旋转照片生成的 XML 需重新预标注才会纠正。

## 为什么不直接选最高分

YOLOE、Grounding DINO 和普通 YOLO 的分数没有统一校准，不能把 0.7 与另一模型的 0.6 直接比较。SAM 的掩码也无法说明对象是猫还是狗。因此跨类别裁决采用同一实例的掩码证据，加上一个额外检测模型的类别判断，并要求原候选中有人支持该类别。该判断仍可能出错，所以必须保留原类别、来源和人工审核标记。对于 YOLO11n 不认识的项目专用类别，当前实现明确弃权。

- [三张样例的现有 XML 与新算法只读预览对照](instance-reconciliation-before-after.png)可直观看到框数与类别的变化。图中的新结果尚未写回项目。

## 正式验收

从尚未人工修改的预标注结果和独立人工真值集构造固定样本，覆盖：单目标多局部框、同类相邻实例、不同类重叠实例、遮挡、小目标、切片边界和项目专用类别。以旧流程与新流程比较：每图候选框数、重复框数、逐类召回率、错误合并数、跨类别裁决正确率、人工修改次数及批次耗时。任何真实目标被合并丢失都应进入失败清单；跨类别自动选类的错误样本必须逐张复盘并收紧门槛。在没有真值集前继续人工审核全部自动裁决结果。
